# Three.js FPS

A simple first-person shooter built with Three.js.

## Controls
- Move: `W` / `A` / `S` / `D`
- Jump: `Space`
- Fire: left click
- Click to lock the pointer and start the game

## Run
Open `index.html` in a browser, or serve the folder from a local static server.

## Notes
- Use the pointer lock to look around and shoot targets.
- Targets move toward the player; let them pass and you lose health.
- Score increases by shooting targets.
